# Voice guide (hi-Latn ↔ en)

Write natively per language — never word-for-word. **Hinglish**: playful, Bollywood-warm, Roman script the way young Indians text; filmy *tone* is fine, film lyrics/dialogue never. **Hindi**: simple, warm, conversational Devanagari; avoid heavy Sanskritised words. **English (Global)**: warm, witty, a little poetic; no Hinglish, no "kindly", no "do the needful".
