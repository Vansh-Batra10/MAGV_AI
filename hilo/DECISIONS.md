# Decisions log

Autonomous build decisions (BUILD_SPEC §20.1). Newest at the bottom.

1. **Location**: the repo already held an unrelated Python project, so Hilo lives in `hilo/` (Vercel root directory = `hilo`). The existing project is untouched.
2. **Versions**: Next.js 16.4 (App Router, Turbopack, `proxy.ts`), React 19.3, Tailwind 4.3, next-intl 4.15, motion 14, zod 4. **TypeScript pinned to 5.9.3** (TS 7 native compiler is new; avoided tooling risk). ESLint 9 (flat config) with `eslint-config-next`.
3. **DB in MOCK mode**: PGlite (embedded Postgres, no Docker). Same SQL migrations run on PGlite and Supabase; RLS lives in `*.supabase.sql`, skipped on PGlite. Queries are serialised for PGlite's single connection.
4. **Auth**: own email-OTP + signed JWT cookie (jose) instead of Supabase Auth, so the app runs with zero credentials. Google sign-in deferred until Supabase Auth is switched on; guest checkout + claim-by-verified-email implemented (on OTP verify).
5. **Passwords**: `bcryptjs` instead of argon2 (pure JS, no native build on serverless).
6. **Payments**: Razorpay via REST (Orders API + Checkout.js + HMAC verification), no SDK. MOCK provider uses the same fulfilment function. MoR slot = `HILO_MOR_PROVIDER` stub.
7. **Routing/editions**: `proxy.ts` rewrites `/`, `/in`, `/in/en`, `/in/hi` marketing paths to `app/m/[site]`; app routes are unprefixed. First-visit geo redirect only (cookie `hilo_site`).
8. **hreflang**: Global English = `en` + `x-default`; India English = `en-IN` (`/in/en`); Hindi = `hi-IN`. Hinglish (`/in`) has no standard tag, so it is served as the India-English variant and links canonically to itself without its own hreflang entry. To verify against Google's hreflang docs before launch.
9. **i18n catalogs**: authored in `messages/src/*.mjs` as `[en, hi-Latn, hi]` triples and built to JSON (`npm run i18n:build`); `scripts/check-i18n.mjs` fails the build on any missing key. Template copy (names, questions, defaults) lives per-language in template defs (§19.4). Legal drafts and internal admin pages are English-only until lawyer-reviewed translations exist.
10. **Hindi (`hi`) UI** shipped early (Release 1) because every key needed a value anyway; copy is serviceable, polish in Release 2.
11. **Template thumbnails**: the real renderer in `thumbnail` mode, mounted only while on screen; poster otherwise.
12. **3D**: R3F only for the Snow Globe (lazy chunk, error-boundary + WebGL detection, 2D canvas fallback). The night globe (Red Thread + home) is an orthographic SVG projection — same look at a fraction of the JS; it is also the 2D fallback.
13. **Form editor**: auto-generated by walking the template's content shape (not zod introspection) — robust across zod versions and covers nested arrays/objects.
14. **Group virtualisation**: corkboard uses `content-visibility: auto` per card (≤100 items) instead of a virtual-list library.
15. **Media access**: `/api/media/*` serves by unguessable 20-char keys (like gift slugs). Storage bucket stays private.
16. **City list**: 208 curated cities (India + diaspora hubs + global) with tz/lat/lon (spec said ~300; expandable in `scripts/cities.txt`).
17. **Free-tier quota**: soft guard on email + IP + anonymous device cookie (3 per 30 days). Email is not OTP-verified for free gifts to keep friction low; signed-in users are keyed by their verified email.
18. **Festival dates**: Diwali 2026 (Nov 8) entered; 2027 dates for Diwali, Holi, Rakhi, Eid, Lunar New Year are marked `verify` (TODO_VERIFY_DATE) and surfaced in `/admin`. Never used silently.
19. **Seasonal takeover**: Christmas uses a 40-day window (launch campaign) and highest priority, so it beats Thanksgiving on the Global edition today. New Year has a 6-day window.
20. **Studio/brand/outbox** are admin-only in production, open in local dev for screenshots and reel capture.
21. **Reels**: Reel Studio renders a 432×768 logical stage scaled 2.5× to exactly 1080×1920 (vector-crisp text).
22. **Release 2/3 features** (Open When, Valentine Week, Unlock Calendar, partners/prepaid codes, guides, `/for/*`) ship as honest "Coming soon" pages; their DB tables and cron endpoints already exist.
23. **MOCK data dir** defaults to `node_modules/.cache/hilo-data` instead of `./.data`: Turbopack watches the whole project (no ignore option in Next 16), so DB/upload writes under `./.data` triggered rebuild + full-page reload loops in dev. Override with `HILO_DATA_DIR`.
24. **canvas-confetti** is imported statically (~10 KB): its lazy chunk 404'd under Turbopack dev and the chunk-load error forced reloads.
25. **E2E runs against `next start`** (production build), not `next dev`: under Playwright mobile emulation Turbopack's dev HMR kept restarting `/create`. Production is what ships; `HILO_OPEN_TOOLS=1` opens the outbox page and fake cron clock for tests only.
26. **Creator skip semantics**: skipping an optional question clears that field (demo content never ships in a real gift); required photo steps need a real upload.
27. **Above-the-fold animation** is transform-only (`.anim-lift`) so hero copy is visible at first paint; starfields run at ~24fps and start after `load`; the hero live demo mounts on idle.
